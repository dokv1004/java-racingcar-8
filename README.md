# java-racingcar-precourse

## 자동차 경주

### 1. 기능 요구 사항
초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

### 2. 요구 사항 분석
입력: 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
<br>
출력: 차수별 실행 결과
<br>
예외처리: 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 발생
1. 자동차 이름 관련
   1. 2개 미만의 자동차 이름을 입력한 경우
   2. 5자 초과의 자동차 이름을 입력한 경우
   3. 중복된 자동차 이름을 입력한 경우
2. 경주 횟수 관련
   1. 양의 정수 외 다른 문자를 입력한 경우

### 3. 구현할 기능 목 (필요기능)

- [ ] 자동차 이름을 입력받는 기능을 구현
  - [ ] 쉼표(,)로 구분, 5자 이하의 자동차 이름을 입력
  - [ ] 이름 앞, 뒤의 공백을 제거
  - [ ] 2개 이상의 자동차, 중복 이름 허용 X
- [ ] 경주 횟수를 입력받는 기능을 구현
  - [ ] 양의 정수만 입력 가능
- [ ] 무작위 수를 추출하여 게임을 진행하는 기능을 구현
  - [ ] 0~9 사이 무작위 정수 추출
- [ ] 게임 진행상황을 출력하는 기능을 구현
  - [ ] 각 차수별 실행결과 출력
  - [ ] 우승자 출력 기능

### 4. 구현 계획
클래스를 나누어 구현을 계획
1. Application 클래스
   - Game 클래스의 게임 시작 메서드를 실행
2. Car 클래스
   - 생성자를 통해 자동차의 이름을 입력 받음
   - 랜덤 정수를 바탕으로 행동을 선택하는 기능
   - 현재 위치를 반환하는 기능
3. Game 클래스
   - 게임 진행 문구 출력
   - 게임 진행 규칙에 따라 게임 진행
4. Validator 클래스
   - 유효성 검증 및 예외처리 기능
